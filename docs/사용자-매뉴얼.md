# 신발자국(족적) 매칭 시스템 — 사용자 매뉴얼

> PPT 삽입용 슬라이드 단위 구성. 「」 안의 텍스트는 화면에 실제로 표시되는 버튼·라벨입니다. (본 매뉴얼은 신발 등록 흐름을 제외한 **사건(현장) 중심** 흐름을 다룹니다.)

---

## 전체 흐름 한눈에

```
[1] 사건 등록          [2] 사건 조회 → 문양 추출 → 검색
─────────────         ──────────────────────────────
이미지 업로드          사건 조회(목록에서 선택)
   ↓                      ↓
이미지 편집            문양 추출 (자동)  ─┐
(회전·크롭·각도보정)      또는              ├→ 신발 검색 → 결과 → 유사부위 표출
   ↓                   문양 수동 삽입   ─┘        (Top-10 대응)
사건 정보 입력            ↓
   ↓                   (선택) 이미지 편집 → 편집 검색
저장                      ↓
                       필수문양 지정 → 실시간 재검색
```

# PART 1. 사건 등록

앱을 실행하면 자동으로 「신규 사건 등록」 화면(`/crimeRegister`)이 열립니다.
화면은 **왼쪽 = 현장 이미지 / 오른쪽 = 사건 정보**의 2열 구조입니다.

---

## 슬라이드 1-1. 현장 이미지 업로드

- 화면 상단 제목: 「신규 사건 등록」 / 부제 「사건 정보를 입력하고 현장 이미지를 관리하세요.」
- 왼쪽 「현장 이미지」 영역의 **「현장 이미지를 업로드하세요」 / 「클릭하여 이미지 파일 선택」** 클릭
- 이미지 파일 선택 → 자동으로 최대 1000px로 축소되어 표시

> 이미지가 없는 상태에서 편집 도구를 누르면 「이미지를 먼저 등록해주세요」 안내가 뜹니다.

---

## 슬라이드 1-2. 이미지 편집 ① — 회전

왼쪽 이미지 위쪽 회전 툴바에서:

| 조작 | 동작 |
|------|------|
| 좌회전 버튼 | 왼쪽으로 90도 회전 |
| 우회전 버튼 | 오른쪽으로 90도 회전 |
| 자유각 슬라이더 | −180° ~ 180° 미세 회전 (현재 각도 배지 표시) |
| 「맞춤」 | 화면에 맞게 |
| 「100%」 | 실제 크기 |

---

## 슬라이드 1-3. 이미지 편집 ② — 도구 도크

왼쪽 하단 「도구」 섹션의 2×2 버튼:

1. **「크롭」** — 클릭 → 뷰포트에서 영역 드래그(안내: 「영역을 드래그한 뒤 크롭 완료」) → **「크롭 완료」** 재클릭
2. **「각도보정」** — 클릭 → 이미지 위 **4개 점을 순서대로 클릭**(빨강·초록·파랑·노랑) → 진행 표시 「n / 4 점」 → 4점 완료 시 자동 보정, 「각도 보정이 완료되었습니다.」
3. **「길이측정」** — 「P1·P2로 1cm 기준 → P3·P4 측정」. P1·P2로 1cm 기준선, P3·P4로 실측 길이(cm)
4. **「전체 초기화」** — 폼·이미지·조정·회전 전체 리셋

---

## 슬라이드 1-4. 이미지 편집 ③ — 가시성 보정

「가시성 보정」 섹션(「실시간 미리보기」) — 슬라이더·토글:

- 「밝기」 / 「대비」 / 「감마」
- **「임계값」** — 지정 밝기 기준 흑/백 이진화 (끄면 「꺼짐」, 기본 127)
- 토글 **「반전」** / **「흑백」**
- 「보정 초기화」

> 하단 상태바에서 「원본」 / 「보정」 뷰를 전환해 비교할 수 있습니다.

---

## 슬라이드 1-5. 사건 정보 입력 & 저장

오른쪽 「사건 정보」 패널에 입력(위→아래 순서):

| 필드 | 필수 여부 |
|------|-----------|
| 「사건등록번호」 (placeholder: 「사건 번호 입력 (필수)」) | **필수** |
| 「이미지 번호」 | 선택 |
| 「사건 이름」 | 선택 |
| 「채취 일시」 (YYYY-MM-DD HH:mm) | 선택 |
| 「의뢰관서」 | 선택 |
| 「발견 방법」 | 선택 |
| 「사건 내용 (선택)」 | 메모용 |

- 하단 **「저장」** 클릭 (저장 중 「저장 중...」)
- 이미지 또는 사건번호 누락 시: 「이미지와 사건 번호는 필수 입력 사항입니다.」
- 성공 시: **「사건이 등록되었습니다.」** → 폼이 비워지고 **다음 사건을 연속 등록**할 수 있습니다.
- 「초기화」 버튼으로 입력 내용을 언제든 비울 수 있습니다.

# PART 2. 사건 조회 → 문양 추출 → 검색

이후 모든 작업은 **하나의 통합 화면 「사건 커맨드센터」**(`/search/:사건번호`)에서 이뤄집니다.

---

## 슬라이드 2-1. 사건 조회 (사건 선택)

- 좌측 사이드바 메뉴 **「사건 조회」** 클릭 → 오른쪽 「사건 탐색」 패널 표시
- 통합검색 바 placeholder: 「사건번호·이미지번호·사건명 검색」 (부분일치)
- **「필터」** 펼치면: 「채취 일시」 / 「의뢰관서」 / 「발견 방법」 (정확일치)
- 사건 카드 **왼쪽 클릭 → 사건 전환**(워크벤치 로드), 카드 우측 **「상세 보기」**로 사건 정보 확인
- 조회 결과 없으면: 「조회된 사건이 없습니다.」

---

## 슬라이드 2-2. 커맨드센터 화면 구성

사건을 선택하면 본문이 4개 열로 열립니다:

| 열 | 이름 | 역할 |
|----|------|------|
| 1열 | 「신발 이미지」 (캔버스) | 현장/편집 이미지 표시·편집 |
| 2열 | 「문양 정보」 | 상/중/하/윤곽 4부위에 문양 배치 (검색 대상) |
| 3열 | 「통합 추출란」 + 「문양 리스트」 | 추출 결과 / 문양 라이브러리 (드래그 소스) |
| 4열 | 「사건 탐색」 | 다른 사건 검색·전환 |

- 상단 헤더 제목: 「사건 커맨드센터」 / 「사건 확인·경계선 분할·문양 추출·신발 검색을 한 화면에서 수행합니다.」

---

## 슬라이드 2-3. 문양 추출 (자동)

> **핵심: 경계선을 직접 그릴 필요가 없습니다.** AI 모델이 현장 이미지 전체를 한 번에 분석합니다.

1. (사건 선택 상태에서) 캔버스 헤더의 **「문양추출」** 버튼 클릭 (진행 중: 「추출중」 / 「패턴 추출 중...」)
2. 추출 결과가 3열 상단 **「통합 추출란」**에 `코드 · 점수(score)` 목록으로 표시
3. 원하는 문양을 **드래그하여 「문양 정보」의 상/중/하/윤곽 존에 배치**
4. 필요 시 캔버스 상단 **「초기화」**로 배치 문양 전체 삭제

- 실패 시: 「패턴 추출 중 오류가 발생했습니다.」

---

## 슬라이드 2-4. 이미지 편집 (검색 전 보정)

캔버스 헤더의 이미지 스와퍼에서 **「편집」**(편집이미지)을 선택하면 하단에 편집 툴바가 열립니다.

편집 도구 4종:

- **「배경제거」** / **「접합장애물제거」** — 좌클릭으로 영역 지정, 우클릭/더블클릭으로 확정(최소 3점)
- **「이진화」** — 「이진화 게이지」(실시간). 모드 칩: 「이진(표준)」·「이진(반전)」·「절단」·「제로화」·「제로화(반전)」 + 「임계값」 슬라이더(0~255) → 「적용」
- **「노이즈제거」** — 「노이즈 제거 실행」 (AI 처리, 다소 시간 소요)

액션: 「되돌리기」 / 「원본 복원」 / **「저장」** (성공: 「편집 이미지가 저장되었습니다.」)

---

## 슬라이드 2-5. 신발 검색 & "편집 검색"

- 캔버스에서 **「현장」 / 「편집」** 뷰를 선택해 **검색에 쓸 이미지**를 정합니다.
  - 「현장」 이미지로 검색 = 일반 검색
  - **「편집」 이미지로 검색 = "편집 검색"** (보정된 이미지 기준)
- 헤더의 **「신발 검색」** 버튼 클릭 → 검색모드(`?mode=search`) 진입
- 화면이 **[이미지 | 문양 정보 | 검색 결과]** 3열로 전환
- **브라우저 뒤로가기**로 문양 추출 상태로 복귀 / 헤더 「검색 종료」로 종료

# PART 3. 검색 세부 기능

---

## 슬라이드 3-1. 문양 수동 넣기 ("그냥 검색")

추출을 쓰지 않고 팔레트에서 직접 문양을 골라 넣는 방법입니다.

**3열 하단 「문양 리스트」에서:**
- 종류 버튼 8종: 「무늬」·「선」·「윤곽」·「다각」·「삼각」·「사각」·「원」·「항목」
- 안내: 「클릭 또는 드래그」 → 「문양 정보에서 선택한 부위로 삽입」

**삽입 방법 2가지:**
1. **클릭 삽입** — 먼저 「문양 정보」의 **부위 헤더를 클릭**해 대상 선택(「대상」 배지 표시) → 팔레트 썸네일 클릭
2. **드래그앤드롭** — 팔레트 썸네일을 **상/중/하/윤곽 존으로 끌어다 놓기**(「여기로 드래그」 / 「여기에 놓기」)

- 이미 넣은 문양은 흐리게 + 체크(「삽입됨」)로 비활성 표시
- 배치 후 「신발 검색」으로 검색

---

## 슬라이드 3-2. 필수문양 지정

검색에는 **"필수"로 지정된 문양만** 사용됩니다.

- 「문양 정보」 존 안의 문양 썸네일을 **우클릭 → "필수" 토글** (툴팁: 「클릭: 삭제 · 우클릭: 필수 토글」)
- 필수 문양은 **빨간 테두리 + 「필수」 배지**로 강조
- **실시간 재검색**: 필수 문양을 켜고 끌 때마다 약 0.3초 뒤 오른쪽 검색 결과가 **자동 갱신**
- (참고) 썸네일 **클릭 = 삭제**, **우클릭 = 필수 토글**

---

## 슬라이드 3-3. 이진화보기 · 유사부위 표출

검색모드 헤더에서:

- **「이진화보기」 / 「원본보기」** 토글 — 후보 신발 이미지를 이진화/원본으로 전환
  - (규약) 이진화/원본을 전환하면 유사부위 표출이 꺼집니다.
- **「유사부위표출보기」** — 검색 시 기본 켜짐인 내부 옵션으로, 현장과 후보 신발의 닮은 부위를 분석하도록 서버에 요청합니다. (별도 토글 버튼 없이 검색에 자동 반영)

---

## 슬라이드 3-4. 검색 결과 보기

오른쪽 **「검색 결과」** 그리드:

- 헤더: 「검색 결과」 · 「총 N건」
- 각 후보 카드: 신발 모델번호(「No. …」), **유사도 %**, 순위 배지(「#순위」), 상위 3위 「TOP N」
- 유사도 색상 등급: **80%↑ 초록 / 60%↑ 주황 / 60%↓ 빨강**
- 로딩: 「신발 검색 중」 / 「DB 매칭 분석 진행 중...」
- 결과 없음: 「검색 결과가 없습니다」 / 「필수 문양을 조정해 다시 검색해 보세요」
- 하단 페이지네이션: 「이전 페이지」 / 「다음 페이지」

---

## 슬라이드 3-5. 유사부위 표출 (Top-10 대응)

결과 카드를 클릭하면:

1. **「정렬 설정」** 시트가 먼저 열림 — 「폴리곤 관심영역과 방향 화살표를 지정해 정렬을 저장합니다」 → **「다음 단계로」**
2. 신발 매칭 상세 화면 진입 → **「Top-10 대응 매칭」** 자동 분석(별도 시작 버튼 없음, 「top-10 대응 분석 중…」)
3. **유사부위 시각화**: 「족적 (현장)」 ↔ 「신발 (등록)」 이미지를 나란히 놓고, 닮은 부위마다 **번호 박스**로 대응 표시
   - 우측 「대응 목록」에서 행을 클릭/호버하면 양쪽 이미지의 해당 부위가 동시에 강조
   - **비교 모드 토글**: 「RGB」(실사) ↔ 「스케치·이진」
4. 하단 판정바에서 **「발견」 / 「불발견」** 판정을 이력에 저장

> 정렬 미설정 등일 때 안내: 「정렬(ROI+방향)이 설정되지 않았습니다. 먼저 정렬을 저장해 주세요.」 → 「정렬 설정하러 가기」

---

## 부록. 검색 이력

- 일반모드 헤더 **「검색 이력」** → 우측 시트(「검색 이력」)
- 테이블 열: 「ID」 / 「등록일시」 / 「순위」 / 「매칭된 신발 정보」 (1~3위 초록 강조)
- 빈 상태: 「저장된 검색 이력이 없습니다.」
