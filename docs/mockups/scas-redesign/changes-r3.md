## 지킨 것
- 숫자는 다른 화면과 같은 예시 값이다: 857건·61.2(S05), 신뢰도 87%·NCC 0.81 등(S06), 감정번호 00001-25-0646(S09).
- 「AI는 추천, 판단과 서명은 감정관」 문구를 제목 아래와 시연 아래에 넣었다. 문양 칩에는 「AI 제안」이라고 적었다.
- 움직임은 CSS 애니메이션만으로 만들었다(스크립트 없음). 운영체제에서 「움직임 줄이기」를 켜면 애니메이션이 꺼지고 다 끝난 상태로 보인다.

## 고친 버그(작업 중)
- 마지막 키프레임에만 `opacity:0`을 적으면, 중간 키프레임에 opacity가 없어서 한 바퀴 내내 조금씩 흐려진다. 그래서 이진화 그림·대응점 선·감정서 줄이 점점 사라졌다. 유지 구간 키프레임에 `opacity:1`을 함께 적어 고쳤다.
