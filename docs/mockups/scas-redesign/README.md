# 족윤적 감정 플랫폼 시안 (SCAS 재설계)

**한 줄 요약**: 경찰청 SCAS(기존 족적 시스템)의 메뉴·화면 순서·라벨은 그대로 두고, 사업계획서(폴리스랩 3.0)의 AI 기능과 역할별 권한을 얹은 화면 시안이다. 앱 코드가 아니라 검토용 정적 HTML이다.

## 보는 법
- `index.html`을 브라우저로 연다(같은 폴더의 `assets/`·`screens/`를 읽는다). 검토용 비공개 링크는 claude.ai Artifact로 올린다.
- 화면마다 오른쪽 위 「SCAS 지금 | 개선안」으로 비교한다. 위쪽 「보는 사람」(수사관·감정관·검증자·관리자)을 바꾸면 메뉴·버튼이 역할에 따라 달라진다.
- 번호 핀(주석) 색: 회색 = SCAS 유지, 주황 = 개선, 청록 = +α(사업계획서 신규), 보라 = 인터뷰 근거.

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 문서 틀(원칙·업무 흐름·역할, 화면 자리, 기능 대조표, 열린 질문) |
| `assets/mockup.css` | 디자인 토큰(police-new 실제 색) + 시안 공통 스타일 |
| `assets/core.js` | 공통 도우미: 앱 셸 `M.shell`, SCAS 와이어프레임 셸 `M.scasShell`, 가짜 밑창 그림 `M.sole`, 문양 아이콘 `M.picon`, 렌더·역할 전환 |
| `screens/sNN-*.js` | 화면 하나씩(`M.add`). S00 로그인 ~ S15 모델 관리 |
| `assets/patterns/*.png` | `src/assets/Patterns`에서 복사한 문양 아이콘 일부 |
| `gap-table.md` | 기능 대조표(화면 주석 자동 집계) |

## 근거 자료(저장소 밖, 민감자료라 커밋하지 않음)
- SCAS 사용 영상 3개 분석: `족적데이터_1802/analysis/scas-video/inventory_5613.md`, `inventory_5614_5616.md`
- 사업계획서·발표자료·실무자 설문: `족적데이터_1802/1. 폴리스랩/`

## 고칠 때
- 수정 요청마다 `index.before-<날짜>-r<N>.html` 백업 → 요청한 화면 파일만 고침 → `changes-r<N>.md`에 기록 → 같은 Artifact 링크로 다시 올림.
- 화면 속 사람·사건 정보는 모두 가짜. 실제 사진·이름을 넣지 않는다.
