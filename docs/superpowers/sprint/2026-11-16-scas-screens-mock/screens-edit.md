## 시안 · 브리프와 다른 점

- S04 검색이력 열: 시안은 SCAS 열(검색번호 · 결과건수 · 검색방법 · 검색결과 · 검색일), 브리프 · 지금 기능 F22는 「ID · 등록일시 · 순위 · 매칭된 신발 정보」 → 지금 데이터(`CrimeHistoryRow`)가 있는 브리프 쪽으로 함. 시안 열을 살릴지 마감 때 확인.
- S04 팔레트 종류: 시안 SCAS 8탭은 「윤곽 · 면 · 내부선 · 삼각 · 사각 · 다각 · 원 · 항목」, 지금 앱 · 브리프는 「무늬 · 선 · 윤곽 · 다각 · 삼각 · 사각 · 원 · 항목」(폴더 이름과 맞음) → 지금 앱 쪽으로 함.
- S04 「검색」 버튼: 계획서는 「신발 검색」이라 부르지만 SCAS 라벨 「검색」을 유지(`title="신발 검색"`).
- S03 B 「보정」 그림은 EvidenceImage 보기 4종(raw · binary · invert · contrast)으로 근사 — 밝기 · 감마 수치는 그림에 안 보임(실제 픽셀 보정은 운영 연결 때 `useImageAdjustments`).
- S03 A/B 전환은 시안의 두 창(나란히) 대신 브리프대로 `Segmented` 한 칸 전환.

## r2 — 「전부 시안 그대로」(spec §13)

공통: 위젯 prop `showPlus?: boolean`(기본 true) 하나로 아래 「+α」를 모두 숨긴다(감싼 요소에 `data-plus`). 진열 페이지는 `showPlus={useDevPlus()}`, 동작 없는 신규 버튼은 `onPlusAction(label)` → 「시안 — 기능 준비 중」 알림.
역할(시안 `data-role` · `data-lock`) → 기능 코드: 기술책임자 칩 = `REPORT_APPROVE`, 수사관 칩 = `CRIME_REGISTER` 있고 `CRIME_SEARCH` 없음, `analyst admin` 잠금 = `EXAM_DECIDE`(관리자는 다 보이고 다 누름 — 시안 CSS 와 같음). S03 「저장」 `investigator analyst admin` = `CRIME_REGISTER`.
**실증 역할 잠금은 `showPlus` 일 때만 건다** — 운영은 `showPlus={false}` 로 시작하는데, 그때 실증 코드(`EXAM_DECIDE`)가 아직 없는 사용자가 잠기지 않게(1차 잠금 기준 그대로). 테스트 「신규 끄기면 실증 역할 잠금을 걸지 않는다」.

S03: 도구 이름(자르기 · 4점 각도 보정 · 길이 측정), 아래 줄 「되돌리기」는 `?plus=0` 에서 확인(켜기면 편집 이력 머리), 「적용」은 「도구 설정」 묶음 안에서(AI 제안 「적용」과 겹침), A/B 전환 대신 두 창 확인. S04: 필수 켜고 끄기는 버튼 이름으로(카드 칩 때문에 「필수」 글자 수가 달라짐), 문양 그림 대체글 앞부분 일치(AI 표시 alt), 검색이력 열.

### 시안과 아직 다른 점 · 이유

- 뒤 화면(S02 사건관리 팝업 흐리게) · 창 겹침(OS 창 레이어) — 진열 페이지는 화면 하나라 그리지 않음.
- S03 「좌우반전」(SCAS 줄)은 주황이지만 비활성(지금 기능 없음 — §13-4 규칙 3). 「평준화 · 상하반전」도 비활성 그대로.
- S03 B 「평준화」 켜짐 칩: 평준화는 지금 기능이 없어 켜질 수 없고, 대신 지금 켜진 보정(밝기 · 반전 …)이 칩으로 뜬다.
- S03 B 확대 · 회전은 그림 상자 안 CSS 변환(보기용 근사). 십자선 · 돋보기는 고정 위치 장식(움직이지 않음).
- S04 팔레트 종류는 지금 앱 8개(무늬 · 선 · 윤곽 · …, 폴더 이름 — `textContent` 로 종류를 읽음) 그대로, 시안 SCAS 8탭(윤곽 · 면 · 내부선 …)과 다름(1차와 같음). 이름 찾기는 이름만(설명 데이터 없음).
- S04 「AI 추출 결과」 목록(1차 F17 자리)은 시안에 없지만 지금 기능이라 그대로 둠. 추출 결과를 부위별 「AI 제안」 카드로 넣는 연결은 운영(부위 정보 있는 응답) 때.
- S04 이력 줄 「검색일」은 `frstRegistDt` 의 월-일(전체는 툴팁).
- 1280 폭: S03 A 캔버스가 좁아 회전 손잡이 꼬리표와 「원본 …」 꼬리표가 살짝 겹친다(장식 · 고정 위치). 문서 가로 넘침 0(1280 · 1440 확인). S04 검색이력은 표 안 가로 스크롤(layout.md).
