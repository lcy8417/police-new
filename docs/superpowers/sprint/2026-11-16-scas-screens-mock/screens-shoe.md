## 담은 것 / 뺀 것 (spec §5-2)

- 담음(규칙 3 SCAS 유지): 검색 폼 라벨 순서, 툴바 원문 순서(목록보기/문양보기 · 조회 · 엑셀 · 삭제 · 승인 · 등록 · 초기화 · 구분선 · 엑셀 일괄 등록). 동작이 없는 엑셀 · 삭제 · 승인 · 엑셀 일괄 등록은 비활성 + 「준비 중」 툴팁.
- 담음(규칙 4 개선): 「문양 입력」 필터 — 지금 `Shoe` 문양 배열로 판정 가능.
- 뺌(규칙 2 +α): 분업 단계 일감, 미승인 막대 · 오늘 승인 진행, 카드 AI 확신도 표, 「AI 추천」 필터, 중복 의심 카드, 인공지능문양관리 · AI 1차 입력 · 확신도 막대 · 가림 표시.
- 뺌(애매 → 노트): 레이어 창의 이전 · 다음 · 그룹등록 · 프린트 · 삭제 · 승인 조건 줄(지금 기능에 없음). 문양 편집(팔레트 · 모두에 넣기)은 S04 자리라 문양정보 탭은 이름 보기만. 제조사 · 상표 · 그룹명의 「조회」 선택창(SCAS 코드 선택 팝업)은 텍스트 입력으로 대신. 등록일자 월 단위 선택기는 두 날짜 입력으로 대신. 승인 · 등록관서 · 화종 · 비고는 `Shoe` 타입에 값이 없어 검색 칸만 있고 목록 열은 없음.

## r2 (전부 시안 그대로)

`showPlus`(기본 true, 진열 `?plus=0`이면 끔) 하나로 신규 요소를 숨기고, 신규 요소 마다 `data-plus`. 진열 `?view=list` · `?tab=pattern`으로 처음 보기를 바꾼다(기본: 문양보기 카드 · 기본정보 탭).

1차 지금 기능과 달라진 것(시안을 따름): 기본 보기가 문양보기, 카드 칩이 「입력/미입력」 대신 작업 상태(신규 켰을 때만), 저장 단추는 기본정보 탭 머리 + 문양정보 탭 「문자열」 줄(시안 자리). 테스트: 표가 필요한 시험은 「목록보기」를 눌러 시작.

시안과 아직 다른 것: 창 머리 오른쪽 안내 글(「뒤 목록은 그대로 깔려 있음 · Esc 닫기」)과 탭 줄의 「닫기」는 넣지 않음(껍데기 머리에 닫기가 이미 있고, 안내는 시안 주석). 창 제목 옆 화류번호 · 「AI 확인 필요」 칩은 껍데기에 칸이 없어 탭 줄로 옮김. 창 상세(가림 · 중복 · 진행)는 신발 한 건(303349)만 값이 있음 — 시안도 한 건 예시. 팔레트 검색칸은 모양만(입력 없음). 번호 핀 · 주석 표식은 시안 해설용이라 제외.
