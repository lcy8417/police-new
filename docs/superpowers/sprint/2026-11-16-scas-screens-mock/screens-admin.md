## 뺀 것 (§5-2)

- S00: AI 감정 시연, 소개 문장 · 숫자 3개, 지난 로그인, 내부망 안내(시안 핀 3), 「남은 시도 n회」(응답에 값 없음), 역할별 첫 화면, 위 기관 띠. 「분실 시 관리자에게 초기화 요청」 문구(지금 앱에 없음). 아래쪽 「인가된 사용자만 접근 … 기록이 저장됩니다」 한 줄은 지금 앱에 있어 유지.
- S13: 운영 상태 타일, 역할 프리셋 표, 사용자별 실제 권한 표, 관리자 변경 이력, 신발 DB 분업, 시안의 역할 4종(수사관 · 감정관 · 기술책임자 · 관리자 — 서버 역할 목록 수사관 · 감정관 · 검증자로 대체), 엑셀, 아이디 · 역할 검색칩(지금 앱에 없음).
- S14: 시간대 차트, 이상 징후, 기록 무결성, 감사 항목 · 다운로드 제한 · 관리자 행위 패널, 관리자 행위 탭, 엑셀 내보내기, 보존 기간, 「대상 번호」 필터(지금 API에 없음), 「더 보기」(지금 앱은 쪽 번호 아닌 더 보기지만 브리프대로 이전 · 다음 쪽).
- 애매해서 뺀 쪽으로 간 것: 「아이디 저장」은 지금 앱에 있어 담음, 상단 「엑셀」 버튼은 뺌.

## 공유 부품에 바란 것 (고치지 않음)

1. `Chip`에 초록(성공 · 사용) · 빨강(실패) 22 높이 변형이 없다 → S13 · S14는 `Chip` + 토큰 색 클래스(`border-ok-line bg-ok-bg text-ok-fg` 등)로 덮었다. 변형 `green` · `red` 추가 요청.
2. `DataGrid`에 행 펼침(다음 줄에 상세 행)이 없다 → S14 로그인 기록 표는 같은 토큰으로 화면 안에서 그린 `SessionTable`(`widgets/admin-logs-screen/ui`). 펼침 지원 시 교체.
3. `DataGrid`에 접근성 이름(`aria-label`)이 없다 → 바깥 `section aria-label`로 대신.
4. `Combobox`에 `id`/라벨 연결이 없다 → S13 소속 관서는 보이는 라벨만, 필터 막대 사용자 · 기능도 동일.
5. `Segmented`에 비활성이 없다 → S14 결과 필터는 로그인 기록 탭에서도 보이고 「기능 기록 탭에만 적용됩니다」 안내를 단다.
6. `Avatar`는 28 고정 → S13 상세는 `className`으로 44를 덮었다(잠금 메모와 같은 사정).
7. `DotGrid`(kit 재내보내기)는 인라인 style · hex 라 S00 바탕에 쓰지 않고 `GlowOrb`만 썼다. 점 격자는 빠짐.

## 알아둘 것

- S00 케이스: `ready · loading · failed · locked · error · password-change`. S14 케이스: 기본 4개 + `full-page`(62개 → 50개 꽉 찬 쪽 확인).
- S00 `status="error"`(서버에 닿지 못함)만 「다시」가 있고, 자격 오류 · 잠금은 칸을 고쳐 다시 제출한다.
- S13 위젯은 `features/admin-users`의 순수 규칙 · 문구를 가져다 쓴다(`index.ts`에 내보내기 줄만 추가, R11). 사용자 추가 창은 지금 앱처럼 기능 권한 체크 12개 · 「본청 소속」 안내 · 「전국 사건 사진」 안내를 담았다. 지금 앱의 추가 창에도 관서 고르기는 없어(새 사용자는 본청, 만든 뒤 상세에서 지정) 같게 뺐다. 상세에는 본청 비직원 관서 안내 · 전국 사진 안내가 있다.
- S14 세션 펼침은 제어형(`expandedSessionIds` + `onToggleSession`)이다. 진열 페이지가 펼칠 때 「불러오는 중 → 불러옴」을 흉내 낸다. 케이스 `exact-page`(딱 50개, 다음 쪽이 빔)에서 빈 쪽에도 쪽 넘김이 남는다.
- 눈으로 본 화면 대조(`check:ui:visual`)와 반응형 폭 확인은 하지 않았다(Task 11).
