### S00 움직임 — 어떻게 옮겼나

- 시안은 요소마다 CSS 키프레임(`anim()`, 14초)을 만든다. 앱은 손 CSS · 인라인 색 금지이고 공용 `index.css` 를 고칠 수 없어, **같은 키프레임(시안 % 그대로)을 Web Animations(`element.animate`)로** 건다(`widgets/login-screen/lib/demo-motion.ts` · `model/demo-clock.ts`). 모든 애니메이션의 `startTime` 을 시연 시작 시각 하나로 맞춰 시안처럼 서로 어긋나지 않는다. 키프레임 속 색은 `var(--t-…)` 로 적고 실행 때 실제 값으로 바꾼다.
- 각 요소의 클래스 모양 = 다 끝난 상태(1위 자리 · 87% · 막대 폭 · 도장 · 이진화). 움직임 줄이기(`prefers-reduced-motion`)거나 `animate` 가 없으면 시계를 끄고 그대로 멈춘다(`data-demo-motion="still"`). 시안 glow(카드 테두리) · 정답 행 강조는 색 키프레임 대신 겹친 칸의 불투명도로 옮겼다.
- 폭: 단계 줄 + 카드 4장은 시안 1440 폭(898px)으로 짜고, 칸이 좁으면 통째로 줄인다(`FitWidth`, 배율은 재서 계산한 transform). 1280 에서 문서 · main 가로 넘침 0 확인. 1920 이상은 내용 최대 폭 1440 가운데.
- 바탕: kit `DotGrid` 는 인라인 style 색이라 쓰지 않고 같은 점 격자를 토큰(`color-mix(var(--t-brand) 18%)`)으로 화면 안에서 그렸다. 빛 번짐 2개는 kit `GlowOrb`.
