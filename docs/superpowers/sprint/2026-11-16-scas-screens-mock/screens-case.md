## 해석 · 부품 메모

- S01 테스트 「첫 3개 라벨 감정번호 · 등록일자 · 사건장소」는 **첫 열**(줄 단위로 읽은 0 · 3 · 6번째)로 해석(시안 DOM 순서는 감정번호 · 문서번호 · 사건명 …).
- 열: 기본 14열(시안 15열 − 사건 진행 열), 「SCAS 열 전체 보기」 25열. 토글 라벨 「기본 보기 14열」.
- S02 의뢰관서 `Combobox`는 접근성 이름 prop이 없어 placeholder 「의뢰관서 검색」로 구분 → **부품 요청**: Combobox에 `aria-label` 전달.
- 업로드 막대 너비는 런타임 퍼센트라 인라인 `style` 한 곳(좌표 아님 — 색 아님).
- kit `Checkbox`는 shadcn 원본(내부 hex 색)을 재내보낸 것이라 시안 색과 다름 → 부품 요청: 토큰색 Checkbox.
- DataGrid 행 높이 44 고정(S02 이미지 목록 시안은 30) · 「새 행 강조」 없음 — 기존 잠금 메모대로.
- 이 갈래에서 `src/App.jsx` · 공유 파일은 건드리지 않음. `user-event` 패키지가 없어 테스트는 `fireEvent` 사용.
